# 狐Tone 2.3.0

多機能エフェクトプラグイン「EffeTune Mixwright」を標準搭載した正式版です。

## 主な変更

- [EffeTune Mixwright](https://github.com/Frieve-A/effetune-mixwright) v0.2.0(Frieve作、MITライセンス)をVST3エフェクトとして同梱しました。インストール直後からエフェクトチェインの「追加」で選択できます。
- 同梱プラグインのライセンス文書を `licenses/EFFETUNE-MIXWRIGHT-LICENSE.txt` に収録しました。
- 2.2.2の安定性強化(音声・MIDI・終了処理の修正一式)を含みます。

## 配布物

- `KitsuneTone-2.3.0-win64-setup.exe`: インストーラ版
- `KitsuneTone-2.3.0-win64-portable.zip`: ポータブル版

狐ToneはLMMSを基盤とするGPL-2.0-or-laterの派生ソフトウェアです。配布物にはライセンス、原作者・貢献者の帰属表示、対応ソースへの案内を収録しています。
